# Tài liệu tham khảo

Thư mục này chứa tài liệu môn **Introduction to Cryptography** (ICT Department, USTH) được dùng trong dự án:

- `session1.pdf` … `Session8.pdf` — slide bài giảng.
- `Lab1.pdf`, `Lab2.pdf`, `Lab3.pdf` — bài thực hành.
- `ElgamalDigitalSignature.pdf` — chương 10, Digital Signatures.
- `AESChapter-Doc2read.pdf`, `Fast Exponentiation.pdf`, `Hash Algorithm from Block Cipher.pdf` — tài liệu đọc thêm.

`_extracted/` chứa văn bản được trích tự động từ các PDF bằng `pypdf`, phục vụ tìm kiếm và tra cứu. Nội dung gốc trong PDF vẫn là nguồn chính xác.
